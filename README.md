# Years-in-pixels

Рабочий пример: https://t.me/PixelYearsBot/Diary

Календарь настроений как Telegram Web App: статический фронтенд, PHP-API, MySQL.

## Установка

1. Залейте `src/` на хостинг и создайте пустую базу.
2. Откройте `api/admin.php` — без конфига страница отдаёт установщик.
3. Впишите доступы к базе, токен бота, при необходимости адрес реле Cloudflare, придумайте
   пароль панели и укажите свой Telegram ID. Кнопки рядом проверяют базу (включая право
   создавать таблицы) и связь с ботом обоими путями — напрямую и через реле.
4. **Установить.** Установщик сам запишет `config.php` (хэш пароля посчитается внутри),
   создаст таблицы и сразу пустит в панель.

Ни SQL, ни правки PHP руками не нужны. Если каталог закрыт на запись, установщик покажет
готовое содержимое `config.php` — создать файл вручную и обновить страницу.

Пароль, список админов и токен потом меняются в панели: **Настройки → Доступ**.

## Обновление работающей установки

Залейте новые файлы поверх старых и откройте `api/admin.php`. Если `config.php` уже есть,
установщик это видит: заголовок «Обновление», доступы к базе и токен подтянуты из конфига
и спрятаны в свёрнутые блоки, спрашивается только пароль панели и Telegram ID.

Данные не трогаются. Установщик умеет ровно две операции — `CREATE TABLE IF NOT EXISTS`
и `ADD COLUMN` для отсутствующих столбцов; удалять таблицы, столбцы или строки он не умеет,
типы существующих столбцов тоже не меняет. Проверка подключения показывает, сколько
пользователей и записей уже в базе, до всяких изменений. Старый `config.php` перед перезаписью
копируется в `config-backup.php`, а прежние `$proxyConfig`, `$connectTimeout` и `$dohUrl`
переезжают в настройки автоматически.

## Панель

`api/admin.php` — настройки, диагностика, журнал, календари пользователей.

- **Диагностика.** Кнопка у каждого канала до Bot API вызывает `getMe` ровно тем способом,
  которым ходит бот: напрямую, через реле Cloudflare, через основной и запасной SOCKS5.
  Отказ показывается с разобранной причиной и подсказкой. Там же `setWebhook`/`getWebhookInfo`,
  проверка своего эндпоинта за реле, права на каталоги, версия PHP и состояние схемы.
- **Настройки.** Порядок и состав каналов, адреса реле и прокси, таймауты, DoH, вебхук, журнал.
  Хранятся в таблице `app_settings`. Секреты уровня «доступ ко всему» — токен бота, доступы к базе,
  список админов, пароль панели — остаются в `config.php`: взлом базы не должен открывать вход в панель.
- **Журнал.** `api/logs/ГГГГ-ММ-ДД.jsonl`, фильтры по уровню, категории и подстроке.
  Категории: `tg`, `webhook`, `api`, `auth`, `db`, `admin`. Секреты вырезаются при записи.
- **Пользователи.** Поиск и просмотр календаря любого пользователя, только чтение.

Вход в панель — из Telegram (аккаунт должен быть в `$admin_ids`) или паролем с компьютера.

## Картинки календарей

Готовая картинка сохраняется в `api/user_screens/` и уходит пользователю по цепочке:

1. **ссылкой** — Telegram скачивает файл сам по адресу из настройки «Публичный адрес файлов»
   (обычно инбаунд-реле). Наш канал наружу при этом почти не нагружен;
2. **загрузкой** — если Telegram не смог скачать, тот же файл уходит телом запроса;
3. **ссылкой текстом** — если не прошло и это, человек хотя бы заберёт картинку руками.

Каждая неудачная попытка попадает в журнал с причиной. В панели, на вкладке «Диагностика»,
есть две кнопки: «Проверить доступность файлов» (кладёт пробный файл и пробует забрать его
снаружи) и «Отправить тестовую картинку себе» (гоняет всю цепочку и говорит, какой способ
сработал). Если сработала загрузка, а не ссылка — реле не отдаёт `user_screens`.

## Каналы связи с Telegram

Запросы к Bot API идут по цепочке включённых каналов сверху вниз, до первого сработавшего.
Отказ самого Telegram (неверный `chat_id`, бот заблокирован) цепочку не продолжает — другой канал
тут не поможет. Каждая неудачная попытка попадает в журнал с причиной.

Каталог `api/logs/` не должен отдаваться браузером. `.htaccess` в `api/` это закрывает,
но **на nginx `.htaccess` не действует** — нужно правило в конфиге сервера. Проверка
«Журнал закрыт снаружи» в панели показывает, как обстоит дело на самом деле.
